# Glossaire

## Interface (DSFR)

**Lien** :
Élément d'interface qui mène l'utilisateur vers un contenu à consulter (voir, lire, consulter), sans l'engager dans une action.
_À éviter_ : bouton de consultation

**Bouton** :
Élément d'interface qui déclenche une action ou engage l'utilisateur dans un parcours : créer, jouer, tester, continuer, annuler, revenir en arrière dans un parcours, envoyer, télécharger ou exporter un fichier, ouvrir une modale, modifier ou supprimer une donnée. Il peut changer de page. Les accès rapides de l'en-tête (Mon compte, Ma structure, Déconnexion) sont des Boutons, par convention DSFR.
_À éviter_ : lien d'action
